# Start here

Your website source is in this folder. Begin with `README.md`.

1. Install Node.js 22 or newer.
2. Open a terminal in this folder and run `npm ci`.
3. Copy `.env.example` to `.env.local`.
4. Run `npm run dev` and open `http://localhost:3000` for the read-only preview.
5. Follow README sections 2–5 to connect Supabase, run the SQL migration, create your administrator, seed your content and enable contact inquiries.
6. Follow README section 7 to deploy to Vercel, with or without a custom domain.

The administrator signs in at `/admin/login`. There is no default password.

After setup, use the dashboard to edit content and photographs. No source-code edits are required for ordinary website maintenance.

The real homepage screenshot is in `docs/homepage-preview.jpg`. The complete testing record is in `docs/TEST-REPORT.md`. Review `docs/CONTENT-SOURCES.md` and the dashboard's verification notes before publishing uncertain credentials or external links.
